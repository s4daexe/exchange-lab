# Exchange Lab 📈

### A Stock Exchange Simulator Built From Scratch in C

Exchange Lab is an educational computer engineering project
focused on understanding how financial exchanges operate.

The goal is to design and implement a stock exchange
simulation, starting with a basic order matching engine
and gradually introducing more advanced data structures,
algorithms, and market visualization.

## 🎯 Project Objectives

- Understand how stock exchanges process buy and sell orders.
- Implement an order matching engine in C.
- Apply data structures and algorithms to financial systems.
- Explore price-time priority and order book management.
- Analyze algorithm efficiency and performance.
- Eventually develop an interactive trading dashboard.
